# ─────────────────────────────────────────────────────────────
# README — Setup rápido
# ─────────────────────────────────────────────────────────────
#
# 1. BANCO DE DADOS
#    Você já tem o banco. Rode apenas as partes do schema.sql
#    que ainda não existem no seu DB:
#    psql -U user -d mxcontrol -f schema.sql
#
# 2. VARIÁVEIS DE AMBIENTE
#    Crie um .env na raiz:
#      DATABASE_URL=postgresql://user:senha@localhost:5432/mxcontrol
#
# 3. INSTALAR DEPENDÊNCIAS
#    pip install -r requirements.txt
#
# 4. RODAR O SERVIDOR
#    uvicorn main:app --reload --host 0.0.0.0 --port 8000
#
# 5. DOCUMENTAÇÃO AUTOMÁTICA
#    Acesse: http://localhost:8000/docs  (Swagger UI)
#            http://localhost:8000/redoc (ReDoc)
#
# 6. FRONTEND REACT
#    cd frontend
#    npm install
#    # Colar Dashboard.jsx em src/App.jsx
#    npm run dev
#
# ─────────────────────────────────────────────────────────────
# ENDPOINTS PRINCIPAIS
# ─────────────────────────────────────────────────────────────
# GET  /eventos                              → listar eventos
# POST /eventos                              → criar evento
# GET  /eventos/{id}/dashboard               → KPIs do dashboard
# GET  /eventos/{id}/inscritos-por-categoria → gráfico donut
# GET  /eventos/{id}/inscricoes              → lista com filtros
# POST /inscricoes                           → nova inscrição
# PATCH /inscricoes/{id}/checkin             → realizar check-in
# PATCH /inscricoes/{id}/confirmar           → confirmar inscrição
# GET  /eventos/{id}/cronograma?data=        → cronograma do dia
# POST /baterias                             → criar bateria
# PATCH /baterias/{id}/status               → atualizar status
# GET  /baterias/{id}/resultados             → resultados da bateria
# POST /resultados                           → registrar resultado
# GET  /eventos/{id}/ranking                 → ranking geral
# GET  /eventos/{id}/comunicados             → comunicados
# POST /comunicados                          → novo comunicado
# GET  /eventos/{id}/financeiro              → receita por cat.
# GET  /pilotos/{id}/area?evento_id=         → app do piloto
# GET  /eventos/{id}/alertas/proximas-baterias → trigger n8n
#
# ─────────────────────────────────────────────────────────────
# n8n — AUTOMAÇÃO DE ALERTAS
# ─────────────────────────────────────────────────────────────
# Crie um workflow no n8n com:
#  1. Trigger: Schedule (a cada 5 min)
#  2. HTTP Request: GET /eventos/{id}/alertas/proximas-baterias
#  3. IF: minutos_restantes <= 30
#  4. WhatsApp API: enviar para piloto.whatsapp
#  5. Email: enviar para piloto.email
